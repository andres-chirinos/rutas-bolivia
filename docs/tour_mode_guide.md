# 🗺️ Modo Tour - Guía de Uso

El dashboard ahora incluye un **Modo Tour** que te permite seleccionar múltiples museos y crear una ruta personalizada que los visite todos.

## 🚀 Cómo usar el Modo Tour

### 1. **Activar el Modo Tour**
- Marca la casilla "Modo Tour (clic para seleccionar)"
- El cursor del mapa cambiará a una cruz
- Aparecerá un panel azul con información del tour

### 2. **Seleccionar Lugares**
- **Haz clic en los museos** en el mapa para agregarlos a tu tour
- Los lugares seleccionados aparecerán con marcadores numerados:
  - 🚩 **Verde**: Lugar de inicio (primer lugar seleccionado)
  - 📍 **Naranja**: Lugares intermedios
  - 🏁 **Rojo**: Destino final (último lugar seleccionado)

### 3. **Gestión del Tour**
- **Eliminar lugares**: Haz clic en los marcadores numerados para quitarlos del tour
- **Limpiar todo**: Usa el botón "Limpiar tour" para empezar de nuevo
- **Reordenar**: Elimina y vuelve a agregar lugares para cambiar el orden

### 4. **Cálculo Automático de Rutas**
- La ruta se calcula automáticamente cuando tienes 2 o más lugares
- Cada segmento del tour se muestra con colores diferentes
- Las transferencias y tipos de transporte se distinguen visualmente

## 🎨 Visualización

### Marcadores del Tour
- **Números**: Orden de visita (1, 2, 3, ...)
- **Colores**: 
  - Verde = Inicio
  - Naranja = Paradas intermedias  
  - Rojo = Final

### Rutas
- **Líneas de colores**: Cada segmento del tour tiene un color diferente
- **Tipos de transporte**: Teleférico (rosa), Bus (azul), Minibus (naranja), etc.
- **Transferencias**: Líneas punteadas más gruesas
- **Caminata**: Líneas verdes punteadas

## 📊 Información del Tour

El panel derecho muestra:

### Resumen del Tour
- Número total de lugares a visitar
- Distancia total del recorrido
- Distancia de caminata vs transporte
- Cantidad de líneas de transporte necesarias

### Itinerario Detallado
- Ruta paso a paso entre cada par de lugares
- Distancia y tipo de transporte para cada segmento
- Líneas específicas a utilizar

## 💡 Consejos de Uso

1. **Planifica el orden**: Piensa en la ubicación geográfica para minimizar recorridos
2. **Considera el tiempo**: Más lugares = más tiempo de viaje
3. **Revisa las transferencias**: El algoritmo optimiza automáticamente las rutas
4. **Usa el panel de capas**: Activa/desactiva diferentes elementos visuales
5. **Combina modos**: Puedes usar tanto el modo normal como el modo tour

## 🔧 Funciones Avanzadas

### Modo Híbrido
- Puedes alternar entre modo normal y modo tour
- El modo normal sigue funcionando para rutas punto a punto

### Gestión de Capas
- Controla la visibilidad de cada elemento
- Reordena capas para mejor visualización
- Elimina capas que no necesites

### Optimización Automática
- El algoritmo considera tipos de transporte
- Minimiza transferencias cuando es posible
- Balancea distancia vs número de líneas utilizadas
